ql.waveforms
===============

The waveforms a :class:`.QProgram` plays are those of the `qprogram <https://github.com/qilimanjaro-tech/qprogram>`_ library, importable from ``qililab``:
:class:`~qililab.Arbitrary`, :class:`~qililab.Chained`, :class:`~qililab.FlatTop`, :class:`~qililab.Gaussian`,
:class:`~qililab.GaussianDragCorrection`, :class:`~qililab.IQDrag`, :class:`~qililab.IQPair`, :class:`~qililab.Ramp`,
:class:`~qililab.Square` and :class:`~qililab.SuddenNetZero`, with :class:`~qililab.Waveform` and
:class:`~qililab.IQWaveform` as their base classes.

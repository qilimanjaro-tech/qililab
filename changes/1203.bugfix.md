`InstrumentFactory.register` and `InstrumentControllerFactory.register` are now typed to return the type of the class you are registering. Before It returned `type[Instrument]` or `type[InstrumentController]`. That caused `isinstance` and `cast` to not narrow down the typing since the class (i.e.) `QDevilQDac2Controller` would be typed `InstrumentController` and not `QDevilQDac2Controller`.

Fixed crosstalk compensation (`QProgram.with_crosstalk_qblox`) crashing on a flux-vs-flux sweep whose two flux loops have different lengths, with `ValueError: operands could not be broadcast together with shapes (39,) (38,)`. The two loops' values were combined element-wise, which only works when both loops have the same length. Offset and gain sweeps are now compensated one loop at a time, so nested loops of any lengths work. `play` waveforms on different buses in the same group must still have the same length.

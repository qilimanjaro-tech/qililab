`NonLinearCrosstalkMatrix` docstrings now describe the sparse parameter layout. The class docstring covers both corrections applied on top of the linear matrix, the Bessel-series term and the junction-asymmetry shift, instead of only the first, and no longer claims that `None` entries mark absent couplings; the storage shape moves to `__init__`, alongside the attributes it describes. `set_non_linear_params` spells out its three-state arguments: omit one to leave the stored value untouched, pass a float to set it, or pass `None` to remove it. `from_linear` no longer says it initialises the nonlinear parameters to `None`.

`get_non_linear_flux_terms` and `flux_to_bias` document the types they actually accept and return, noting that scalar and array flux values can be mixed in one call, so a parked bus can accompany a swept one.

Fixed bus pulse distortions being applied twice in `Platform.execute_qprograms_parallel`. Distortions are applied at compile time by `QbloxCompiler`, which both `execute_qprogram` and `execute_qprograms_parallel` go through, but the parallel execution also applied them again to the compiled sequences before uploading them. The parallel execution now relies only on the compile-time distortions, like `execute_qprogram`.

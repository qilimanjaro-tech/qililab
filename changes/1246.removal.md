Deprecated the `"lo"` and `"lo_and_sidebands"` values of the `cal_type` argument of `Platform.calibrate_mixers`, `QbloxQCMRF.calibrate_mixers` and `QbloxQRMRF.calibrate_mixers`, which now raise a `FutureWarning`. Use `"lo only"` and `"lo and sidebands"` instead (or the new `MixerCalibrationType` enum), the same values as the runcard's LO calibration settings.

Deprecated the `"lo"` and `"lo_and_sidebands"` values of the `cal_type` argument of `Platform.calibrate_mixers`, `QbloxQCMRF.calibrate_mixers` and `QbloxQRMRF.calibrate_mixers`: they now raise a `FutureWarning`. Use `"lo only"` and `"lo and sidebands"` (or the new `MixerCalibrationType` enum), the same values as the runcard's `*_lo_freq_cal_type_default` fields.

Fixed crosstalk compensation (`QProgram.with_crosstalk_qblox`) raising `ValueError: Step value cannot be zero` when a swept loop has no effect on one of the buses, for example with an identity, diagonal or triangular crosstalk matrix. No compensated loop is created for such a bus any more, and the bias it still needs (a fixed flux set in the same block, or the calibrated `flux_offsets`) is applied as a constant. With an identity matrix and no `flux_offsets`, the compensated program now applies the same offsets as the original one.

Fixed crosstalk compensation (`QProgram.with_crosstalk_qblox`) raising `ValueError: Step value cannot be zero` when the crosstalk matrix has zero off-diagonal terms (an identity or purely diagonal matrix). A zero cross-term produced a constant, step-0 compensation `ForLoop` that the Qblox parallel compiler rejects. Such zero contributions are now dropped (no compensation loop and no summed term; a bus with only a constant contribution emits a fixed offset instead), so an identity or diagonal matrix compiles to exactly the same result as running without crosstalk.

`Platform.session()` now yields a `Session` object (`with platform.session() as session: ...`) exposing `execution_time`, `success`, and `error` for the code run inside the `with` block, populated whether it completes successfully or raises. A session is only considered successful if it runs start to finish without any error, including errors raised while cleaning up (e.g. `disconnect()` failing after a successful execution). `execution_time` is also logged via `logger.info`.

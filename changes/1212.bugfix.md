Fixed `Platform.set_bias_to_zero` leaving the tracked `Parameter.FLUX` value stale. The instrument bias was correctly driven to 0 V/A, but the cached `flux_parameter` was never updated, so `get_parameter(alias, Parameter.FLUX)` kept returning the previous (non-zero) value. `set_bias_to_zero` now updates the tracked `Parameter.FLUX` for each bus to the flux that corresponds to zero bias.

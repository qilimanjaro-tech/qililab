Fixed crosstalk compensation (`QProgram.with_crosstalk_qblox`) applying an incorrect bias when the flux offsets of a flux-vs-flux sweep are set at different loop levels (e.g. `set_offset(flux_1)` in the outer loop and `set_offset(flux_2)` in the inner loop). The per-level compensated `set_offset` for a bus overwrote the outer level's contribution instead of adding to it, so the applied bias silently omitted the outer variable's crosstalk term. Compensation is now decomposed per loop nesting depth (lockstep parallel/single loops keep their combined register, nested loops are decomposed per variable), and outer contributions are carried inward and summed at the innermost point. The result now matches the equivalent sweep with both offsets set in the innermost loop, so existing production qprograms no longer need to be changed.
